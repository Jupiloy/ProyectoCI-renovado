🔥 Capítulo 11 · Análisis cuantitativo

🔎 ¿De qué trata esta categoría?

El análisis cuantitativo es el proceso de aplicar técnicas estadísticas para interpretar los
datos recolectados. Aquí se busca:
●​ Seleccionar la prueba estadística adecuada según el tipo de variables y diseño de
investigación.​
●​ Elaborar un plan claro que indique qué análisis se aplicarán y en qué orden.​
●​ Redactar los resultados con el formato académico adecuado (ej. APA 7).​

El objetivo es que al terminar este capítulo tengas un plan de análisis numérico estructurado
y resultados listos para presentar.

🛠️ Cómo aplicar los prompts de este capítulo
1.​ Elige la prueba adecuada: según la escala de medida (nominal, ordinal, intervalo,
razón), normalidad de los datos y número de grupos/variables.​
2.​ Planifica los análisis: define cuáles son principales (para hipótesis) y cuáles son
exploratorios.​
3.​ Reporta con claridad: usa tablas, gráficos y formato APA para que tus resultados
sean entendidos fácilmente.​
4.​ No abuses de la estadística: la prueba más compleja no siempre es la más útil; la
clave es coherencia con tus objetivos e hipótesis.

Prompt #41: Árbol de decisión estadístico

👉 Objetivo: elegir la prueba estadística correcta.
Prompt:

Actúa como estadístico experto. Construye un árbol de decisión estadístico
para mi investigación [TEMA].​
Incluye:
➔​ Tipo de variable (nominal, ordinal, intervalo, razón).​
➔​ Número de grupos/comparaciones.​
➔​ Supuestos de normalidad y homogeneidad.​
➔​ Pruebas estadísticas recomendadas en cada caso (t de Student,
ANOVA, regresión, χ², correlación, etc.).​

🔹 Prompt 42: Plan de análisis

👉 Objetivo: organizar las pruebas y pasos del análisis cuantitativo.
Prompt:
Elabora un plan de análisis cuantitativo para mi tesis [TEMA].​
Incluye:
➔​ Pruebas principales para las hipótesis.​
➔​ Pruebas secundarias o exploratorias.​
➔​ Estrategias para verificar supuestos (ej. normalidad, homocedasticidad).​
➔​ Correcciones por comparaciones múltiples si aplica.​
➔​ Análisis de sensibilidad en caso de datos incompletos.​
